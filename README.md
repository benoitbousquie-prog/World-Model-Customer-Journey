# Can World Models Optimize Customer Journeys and Lifetime Value?

This repository contains a diagnostic, simulation-based framework to study world-model planning for customer journeys / CLV optimization.

## Paper
- PDF: `main_full.pdf`
- arXiv source bundle: `arxiv_src.zip` (and `arxiv_src/` folder)

## Key result (one sentence)
World-model planning trained on confounded “business-as-usual” logs can become over-optimistic at longer horizons (reality gap), while randomized logs are more conservative on the analyzed subset.
